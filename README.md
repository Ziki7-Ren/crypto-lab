## 已实现
- GF(2^8) 运算：xtime / gmul（对拍 0x57×0x83=0xc1）
- AES-128 加密：SubBytes / ShiftRows / MixColumns / AddRoundKey + 密钥扩展 + 10 轮
- AES-128 解密：三个逆变换 + 解密主循环
- AES 标准向量对拍：FIPS-197 App.B / App.C.1 / 全零 KAT，加解密均通过
- SM4 加解密：S 盒现场生成（仿射→求逆→仿射）+ T/T' 变换 + 密钥扩展 32 把 + 32 轮 + 反序变换
- SM4 标准向量对拍：GB/T 32907 附录 A 示例 1（密文 681EDF34…4246）+ 示例 2（100 万次）+ 解密还原
- SM3 哈希：填充 + 消息扩展(16→68 字) + 压缩函数(8 状态字滚 64 轮) + 摘要拼接
- SM3 标准向量对拍：GB/T 32905 附录 A 示例 1（"abc" → 66c7f0f4…8f4ba8e0）+ 示例 2（"abcd"×16 → debe9ff9…9c0c5732）

## 踩过的坑
- 状态是列优先 data[r+4*c]，行优先会全错
- 循环体缩进必须同层（gmul 曾因缩进错算成 0xf9）
- append() 用圆括号，SBOX[v] 用方括号
- SM4 的 S 盒别手抄长串（连抄错 4 次），用数学定义现场生成 + 关键点校验
- SM3 所有加法后必须 & 0xFFFFFFFF 截成 32 位，不截数字会膨胀（实跑 3 轮就从 32 位涨到 88 位）
